# Daal CRM Website

وب‌سایت معرفی عمومی سامانه مدیریت مشتریان دال.

این ریپو فقط Landing و محتوای بازاریابی/SEO را نگه می‌دارد. خود CRM و محیط دمو در ریپوی محصول [`DaalCRM`](https://github.com/plilian/DaalCRM) هستند.

## اجرا

```bash
npm install
npm run dev
```

برای اتصال CTAها به محیط CRM، مقدار `VITE_CRM_URL` را در `.env` تنظیم کنید. در حالت توسعه، مقدار پیش‌فرض `http://localhost:3000` است.
